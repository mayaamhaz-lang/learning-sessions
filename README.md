# Learning sessions

Six sessions with all 31 MP4 videos bundled locally.

## Publish with GitHub Pages
Upload the contents of this directory to the root of a GitHub repository. Keep all session folders intact. In Settings → Pages, choose Deploy from a branch, main, / (root), and Save.

Use https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/session-1/ in the first lesson iframe, and session-2/ through session-6/ for the others. The root URL displays a session menu.

These files become publicly accessible when published on a public Pages site. The platform must allow the external Pages URL and JavaScript. Autoplay with sound may require a user click.

Example iframe:

```html
<iframe src="https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/session-1/" title="Session 1" width="100%" height="800" allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Validation: all 31 video references resolve to included MP4 files; static src/poster references checked. Playback on the published site and inside your platform still needs testing.
